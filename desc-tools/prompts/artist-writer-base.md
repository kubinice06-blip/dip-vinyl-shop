# 藝人介紹・寫作層共用規則

工作目錄一律 `desc-tools/`（雲端）或 `desc-restyle/`（本機）。**不動任何 git、不動 PROJECT_MEMORY.md、不上網。**
臨時檔一律加批名與組別前綴。

**先讀 `prompts/writer-base.md` 的「文字」「來源平台與樂評姓名不進正文」「榜單、獎項、名人堂」
「拉丁專名的數量上限」四節**，那些規則全部適用。其餘專講專輯簡介結構的段落（hook、note、主故事鏈）不適用。

## 輸入

`batches/artist/research/<批名>-g*.json`：每位藝人的三格（`origin` 身世與養成／`sound` 音樂貢獻／`legacy` 影響與地位）、輔助的 `era` 與里程碑，每條附來源。
**只用這裡的事實**，不得補充外部知識。`conflicts` 列出的是已裁定的衝突，照裁定結果寫。

## 寫什麼（2026-09-29 店主改定方向）

這是點藝人名時跳出的小視窗，讀者剛看完一張專輯卡，想知道「這個人是誰、為什麼重要」。
**讀完要答得出兩件事：他從哪裡來、他在音樂史或這個場景裡有多重。**

店主看完試做稿的評語：「都在講他幾年在哪幹嘛，很無聊。看完介紹看不出鄧麗君是台灣最有影響力的歌手。」
所以**不寫履歷，寫人**。範例（店主核可方向）：`batches/artist/output/ar-trial-mix-out.json` 的鄧麗君。

骨架（依材料取捨，但三個重心都要有）：

1. **身世與養成**（一至兩句）：出身、家庭、族群或文化背景、怎麼走上音樂。
   **只寫真正塑造他音樂的背景**（鄧麗君的外省軍人家庭、眷村、父母的京劇與黃梅調就是）。
2. **音樂貢獻**（主體，兩句）：他的聲音或手法辨識度在哪、開創了什麼、改變了什麼。
3. **影響與地位**（一至兩句）：誰受他影響、跨地域或社會層面的現象、**有出處支撐的共識評價**
   （「被視為…最…之一」、名人堂、國家級榮譽、葬禮或紀念的規模、後輩點名受他影響）。
4. **收尾**落在他留下的東西（事實），**嚴禁格言或評語式收語**。

### 反流水帳（硬規則）

- **全文的四位數年份至多 4 個**（生卒算在內）。年份只留在關鍵轉折上。
- **不得連續兩句以「某年」開頭**（「1970 年代後期」這類時期不算）。
- 簽約、轉廠牌、發片日期、巡演、單曲名次這類履歷資訊，**只在它本身就是轉折或成就時才寫**，否則整條捨去。
- 事件寫「它代表什麼」，不是「它發生了」：寫「歌聲靠翻錄卡帶流進中國大陸，雖被斥為靡靡之音仍流傳『白天聽老鄧，晚上聽小鄧』」，
  不寫「1979 年起歌曲傳入中國大陸」。

### 份量要寫出來

- 輸入裡有出處支撐的最高級評價（`legacy` 格），**一定要寫進正文**，不要謙虛掉；這是讀者最想知道的事。
- 但**只能轉述有出處的共識**，不可自己下評語（不寫「偉大」「無人能及」）。
- 素材裡真的沒有地位層級的事實，就把音樂貢獻寫深，不要硬湊評價。

### 其他

- **專輯名至多點一張**。那是專輯卡的工作，這裡講人。代表曲可點一至兩首。
- 開頭**不得**是「這位」「他是」「她是」「本團」「身為」；也不以藝人名加「是」起句。
- 逝世、解散寫成過去的事實，**不寫「至今仍活躍」「目前」這類會過期的現在式**；在世者不用「一生」。
- 本卡藝人名照名冊 `name` 逐字寫。內文提到其他東亞音樂人照原文漢字（見 writer-base「文字」節）。
- 大類曲風用中文（爵士、靈魂樂、放克），次類型用英文（hard bop、soul jazz、free jazz）。
- 禁你我；禁「傳奇」「傑作」「必聽」「里程碑」「獨樹一格」「融合多種元素」「具有代表性」「層次豐富」「不可或缺」。

## 字數

`Array.from(intro).length` 計，含空格：

| status | 區間 | 硬上限 |
|---|---|---|
| full | 180–250 | 250 |
| thin | 100–160 | 160 |

照 writer-base 的硬程序：**動筆前逐位列預算表、專名壓到 3 個以內、寫完逐位實測兩端**，
超標時整格捨去，不逐字削。**絕不先寫長再刪。**

## 輸出

`batches/artist/output/<批名>-out.json`，陣列：

```json
{ "key": "lee morgan", "name": "Lee Morgan", "status": "full",
  "intro": "…",
  "src": ["https://…", "https://…"] }
```

`src` 列出正文實際用到的事實來源網址（至少兩條、去重）。

## 紀律

- **每寫完 5 位就把目前結果寫進輸出檔**；輸出檔已有內容就讀進來接續，不要從頭重寫。
- 回報只寫：完成幾位、各位字數、哪幾位素材不足改寫 thin、輸入裡看到的疑點。**不要覆述正文。**
