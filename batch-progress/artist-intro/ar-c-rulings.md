# 藝人介紹 C 級裁定（ar-c-*）

C 級（卡池 2 張）審稿深度比照 A／B 級逐位審（計畫書 §7-4 未定案，取較嚴一邊）。合作型與編制名稱以卡上字串為一位，以領隊或搭檔為主體，寫明是哪一個編制名義。其他通則沿用 `ar-b-rulings.md`。
