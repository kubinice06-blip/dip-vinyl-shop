## 五、⚠ 這批立的三條流程裁定（303／305，與 c-126 的坑不同）

1. **第 303 條：代理被砍掉時先看輸出檔，再決定要不要重派。**
   研究 a 組**死於 API 內容過濾**，最後一句是「Now I'll write the output file in chunks.
   Starting with cards 0–4」——**看起來像才寫到第五張**。
   **實際上檔案是完整的 23/23**（全 full、每張 4–5 條 facts、22 張帶逐軌比對的串流採信）。
   **被擋掉的是回報，不是工作。** 代價：回報裡的摘要真的沒了，
   **所以研究層的注記本身要能當紀錄用。**
2. **第 305 條：人名禁令會在 hook 層漏出去。**
   三張的 `note` 正文指示裡出現了研究層 `⚠` 明令不得寫的人名
   （告五人《帶你飛》的三位製作人、椅子樂團《Love Dialogue》的製作人、
   法蘭黛《受寵若驚》的母帶工程師）。**洩漏路徑**：人名在 `facts` 裡（研究層要留證據鏈）、
   `⚠` 在同一份 `notes` 裡說不准寫，**hook 層讀了 `facts` 卻沒把 `⚠` 套到自己寫的 `note` 上**。
   寫作層三張全部照 `⚠` 辦。**主線複驗要掃人名，不能只掃字數與禁語。**
3. **主線派工詞又錯兩處**（第 253 條同型第四次）：
   我把 Dear Musik 那件事掛到黃宇寒（實屬光引擎）、我寫「無試聽 1 張」（實為 2 張）。
   **兩處都是 hook 層照研究稿擋下來的。**
