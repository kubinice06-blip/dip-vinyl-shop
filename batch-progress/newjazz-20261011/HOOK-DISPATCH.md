# 新世代爵士線鉤子層派工（add-20261012-nj1…nj5 共用）

你是 dip vinyl 的**鉤子層**，全程台灣繁體中文。派工訊息會告訴你：**批名**與**你負責的研究組**（例：a、b、c）。另一位代理同時做其餘組，不要碰他的檔。

## 一、先讀（逐字讀完再動手）
1. `desc-tools/prompts/hook-base.md`——**全檔**，規格本體（開頭「雲端註記」三點全部適用：輸出路徑、note 預算公式、骨架歸屬寫法）。
2. `batch-progress/<批名>/rulings.md`——**全檔**（主線策展＋研究 a–e 五段；研究層推翻策展層的一律以研究稿為準）。
3. 研究稿：`desc-tools/batches/research/<批名>-<組>.json`（你負責的那幾組；另外幾組也讀，用來做全批反同構）。
4. 寫法先例：`batch-progress/add-20261006-shop/rulings.md` 的「鉤子層（8745–8754）」整段（骨架分配、hook 四型、日期「日」後一字配死、開頭兩句讓不懂的人知道是誰）。

**輸出**：每個研究組一個檔：`desc-tools/batches/hooks/<批名>-hooks-<組>.json`。**key 逐字複製研究稿、順序不變，欄位只有 `key`／`hook`／`note`。** 張數以研究稿為準，開工先自己數。

## 二、預算公式（寫死）
```
預算 ＝ Array.from(hook).length ＋ Array.from(note).length
       − 「主故事：」 − 每個「→」 − 「正文只寫上列各項。」 − 「這條骨架全批只走本張。」
```
**只扣這四樣，上限 230**；hook 加權 ≤ 50（ASCII 算 0.5），**hook 原始字元壓到 30 以內**（英文團名多的這條線特別容易爆）。note ≤ 350。算不下就在這一層整格捨去。

## 三、這條線的重點
- **骨架**：全批 39–40 張不得同構。新世代爵士常見骨架——「冷門樂器當 leader（低音號、豎琴、長號）」「培育體系出身（Tomorrow's Warriors／AACM）」「團員單飛的個人盤」「現場一次錄完」「爵士×嘻哈製作人」「向前輩致敬（Komeda、Sun Ra、Coltrane）」「社會議題／身分書寫」「大樂團作曲家」「地方場景（倫敦南區／芝加哥／奧斯陸／東京）」「首張即代表作」「遺作」等——**每條骨架全批只准一張**，配表寫進 rulings。
- **2026-10-06 新規：開頭兩句要讓不懂的人知道是誰**（身分或樂種）：hook 只帶名字的，note 指派第二句補身分。
- 要讓讀者知道**誰當 leader、吹／彈什麼、編制長什麼樣**；聲音描述要有 facts 撐（節奏、樂器配置、錄音方式），不准用空泛形容詞堆砌。同一場景（倫敦南區、International Anthem）的卡多，場景介紹全批只准一張當主軸。
- 「日」後一字逐張配死（`/[年月]\s*\d{1,2}\s*日(.)/`），日期＋動詞的形狀一張一種。
- 同一藝人跨兩張以上時分軸（一張帶生平、一張帶錄音細節），「他／她／他們」引入法配表給寫作層。
- 「不得寫 X」一律改寫成「這一格不寫」——否定句會被寫作層照抄。研究稿 notes 的「uncertain」「查無」格子整格捨去。

## 四、續跑
**每做完 5 筆就把目前結果整份寫回對應輸出檔**；輸出檔已有內容就先讀、接續補完，不要從頭重寫。判斷檔案在不在用 `ls`／讀檔，不要用 `git status`。

- 自己逐筆算預算寫進報告；hook 與 hook 之間掃一次中文 4-gram（專名、樂器名不算）。

## 六、裁定
