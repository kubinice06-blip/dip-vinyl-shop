# 三軸重評標準（2026-11-01）

**店主**（2026-11-01）：
- 「Yancy Körössy 那張怎麼可能都只有三顆星？你的判斷標準是不是已經失準了」
- 「後來補上的頻率缺口全部都要檢查」

## 查到的失準

| 線 | 張數 | 經典度 3 的比例 | 冷門度 5 的比例 |
|---|---:|---:|---:|
| 情緒薄格（md／mc／ml） | 2,345 | 86% | 43% |
| Spotify 補卡（sf） | 417 | 81% | 4% |
| 鐵幕爵士（eb） | 195 | 88% | 16% |
| 全卡池（對照） | — | 42% | — |

三個成因：

1. **經典度沒有錨點**：人工評分表（§0.8 depth／regional rubric）只替冷門度定了錨點。工作階段遇到非英語圈或深掘盤，就整批填 3，例如「該國爵士史代表盤，無國際正典地位 → 3」。
2. **冷門度直接套 Last.fm 絕對分級**：worker 的 `/album-rating` 把考古再發盤、非英語圈盤一律打成 5，§0.8 說這正是要人工校正的情況。情緒薄格線 2,345 張裡有 2,025 張是 worker 值。
3. **硬蕊度方向搞反**（eb1 實例）：把它當「易聽度」打，自由爵士給 2、人聲和排簫給 4。正確方向是**硬蕊度＝入耳難度，5＝晦澀前衛，1＝旋律親切**。

## 三軸定義與錨點（重評一律照這份）

### 經典度 classic：這張錄音在它所屬場景裡的地位

尺度是**它所屬的場景**，可能是國家、語言圈、類型或廠牌。不是「全球正典」。

非英語圈的里程碑可以拿 5，條件是要有可查的依據。

| 分 | 錨點 | 依據例 |
|---|---|---|
| **5** | 該場景公認的里程碑或必聽盤：場景史一定會講到；有權威榜單、正典書目，或大廠／考古廠的正式再版系列 | 1001 Albums、Penguin Guide 皇冠或四星、AllMusic 5 星或 AMG Pick、RYM 該類型前段；該國權威榜（如匈牙利 Szabados《Az esküvő》）；Jazzman／Numero／LITA／MPS 再版系列 |
| **4** | 藝人公認的代表作，或場景裡的重要作品：評論共識是強作，常被推薦 | 藝人生涯最受肯定的一兩張；場景回顧文章會列出的盤 |
| **3** | 有明確地位或特色，但不是代表作，或場景內評價中等 | 藝人中期佳作；場景二線的穩定作品 |
| **2** | 合格、非首選；評價平淡或混雜 | — |
| **1** | 評價差，或只有歷史意義 | — |

- **藝人自己的代表作至少給 4**，除非評論共識明確認為那張平庸。
- 這條線收進來的卡，多數都是因為「是某位藝人或某個場景的代表作」才入選。分布偏向 3–4、少數 5，才是合理的，不該全擠在 3。

### 冷門度 obscurity：玩家撞見這份錄音的機率

照 `ALBUM_ONBOARDING.md` §0.8 錨點制，以**該語言圈／該場景**為尺度。

| 分 | 錨點 |
|---|---|
| **5** | 原盤是私壓或極小廠，壓量或通路有據極小，**而且**沒有進入串流的授權再發 |
| **4** | 原盤如上，但已有授權考古再發進入串流（仍屬收藏家領域） |
| **3** | 原盤由正規廠牌發行，但當年商業失敗或發行有限；或是該語言圈的一線作品，在圈外幾乎無人知 |
| **2** | 正規廠牌正常流通，有國際發行或在該語言圈主流流通 |
| **1** | 入門名單常客 |

- Last.fm listeners 只當**報警**用，不當分數來源。
- 有正式串流再發的考古盤最多 4。
- 國營唱片廠（Electrecord、Hungaroton、Supraphon、Muza、Melodiya、Amiga 等）在本國是主流通路，通常給 3；有國際再發的看情況給 3–4。
- MPS／ECM／Blue Note 這類國際廠牌的正規發行通常給 2–3。

### 硬蕊度 accessibility：入耳難度（**不是好聽度**）

| 分 | 錨點 |
|---|---|
| **1** | 旋律直白、流行歌結構、柔和 |
| **2** | 主流易聽，有一點門檻 |
| **3** | 需要投入：長篇、器樂即興、單一音色長時間 |
| **4** | 不協和、自由即興、噪音成分、無調 |
| **5** | 前衛、噪音、概念、極端 |

- 參考：Sade／Norah Jones 是 1；Cecil Taylor 是 5；Albert Ayler 是 4。
- dark ambient／drone 通常 3–4；dub、soul、R&B 慢歌通常 1–2；自由爵士 4–5；主流 bop 2–3。

## 稀有度（不必手算，套用時重算）

`score = classic + accessibility + (obscurity>=5 ? 1 : 0)`

- 10 以上 legendary
- 8 以上 epic
- 6 以上 uncommon
- 4 以上 rare
- 其餘 common
