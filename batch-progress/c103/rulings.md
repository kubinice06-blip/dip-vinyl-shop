## 1. **§5.6 一次都沒開**——派工信預告錯了，第 167 條在演歌線同樣成立

派工信（`CURATION-BRIEF-c103plus.md` 第三節）寫「MB 建檔率低，正典多為精選集（走 §5.6，每張 `exceptionReason`＋2 URLs）」。
**實掃結果與這個預期相反的地方不在「是不是精選」，而在 MB 怎麼標它。**

| | 筆數 |
|---|---:|
| 掃過的 release-group | 1,297 |
| `primary-type=Album` | 696 |
| 其中 `secondary-types` 為空 | 453 |
| **`primary-type=Compilation`** | **0** |

**裁定：照第 167 條，判準是 `primary-type` 這個欄位本身，不是「這張碟在現實中是不是精選」。**
演歌線的「全曲集」「ベスト」「大全集」在 MB 一律建成 `primary-type=Album` ＋ `secondary-types=[Compilation]`，
依 §5.6 明文照一般 Album 寫、例外欄位留空——填了會被 `chk-prop` 判「非合輯卻帶例外欄位」（c-90 裁定第 3 條）。
**本批 44 張全部 `releaseType: "Album"`、`exceptionReason` 與 `exceptionEvidenceUrls` 全空。**

這是第 167 條在爵士／藍調（c-95）、民謠鄉村（c-98）、古典（c-100）之外的**第四批印證**，
累計 **7,766 個 RG、`primary-type=Compilation` 依然是 0**。往後的派工信不要再對任何曲風預告「§5.6 會用得很兇」。

## 2. **全假名藝名要不要羅馬化：ちあきなおみ 寫假名，不寫 Naomi Chiaki**

2026-08-11 東亞裁定的例外條是「**完全無漢字**的名字才用羅馬字」，`はっぴいえんど`→`Happy End` 是這條的先例。
`ちあきなおみ` 是全平假名，字面上落在同一個例外裡。**本批不照那個字面走。**

三個理由：

1. **MB 自己兩種都用。** 同一位藝人 1970／1972 那三筆 RG 的 artist-credit 是羅馬字 `Naomi Chiaki`，
   1972-12 之後（含 1985《港が見える丘》）是假名 `ちあきなおみ`。**不是「MB 用羅馬字」，是 MB 內部就分裂。**
2. **第 177 條的順序是「先看池中、再看 MB credit」**，不是「先套命名裁定」。池中 0 張，
   MB 較新且較多數的 credit 是假名。
3. **`Happy End` 那條先例的理由是「樂團自己有正式的英文名」**——`Happy End` 是團名的官方羅馬字，
   印在唱片上。`Naomi Chiaki` 沒有這個地位，它只是拼音轉寫。

**立案：全假名藝名只有在「該藝人／團體自己有正式的羅馬字名」時才羅馬化；
單純的拼音轉寫不構成羅馬化的理由。** 依此，`ちあきなおみ` 保留假名，`Naomi Chiaki` 進 `queryAlias`。
（可逆：改的是卡單掛名欄，不是卡池結構。）

## 3. ⚠ **新形狀：掛名分裂發生在 MB 內部，不只在池中**

`audits/pool-artist-name-splits.md` 記的 24 組都是**池中**的分裂（同一人兩張卡兩種寫法）。
本批撞到的是另一種：**同一位藝人在 MB 不同 release-group 上掛兩種 artist-credit。**

| 藝人 | MB 的兩種 credit | 出現在 |
|---|---|---|
| 石川さゆり | `Sayuri Ishikawa` ／ `石川さゆり` | 《あなたの私》1975 是羅馬字，1979 之後是漢字假名 |
| ちあきなおみ | `Naomi Chiaki` ／ `ちあきなおみ` | 1970／1972 兩筆是羅馬字，1972-12 之後是假名 |
| 由紀さおり | `Saori Yuki` ／ `由紀さおり` | 《由紀さおりの美しき世界》1969 與《Saori Yuki Sings Standards》1970 是羅馬字 |
| 江利チエミ | `Chiemi Eri` ／ `江利チエミ` | 《チエミの民謡集》1958 是羅馬字（且是合掛名） |

**裁定：一律取原文形（漢字／假名）當卡片掛名，羅馬字寫進 `queryAlias`，並在 `mbNote` 明記「本 RG 的 credit 是 X」。**
這與第 6／70／120 條（用 MB 實體的文字）不衝突——**那三條講的是同一實體有唯一寫法時要照抄，
這裡是同一實體有兩種寫法，順序才由第 177 條決定。**

**這一條要回寫 `audits/pool-artist-name-splits.md`**：往後的撞卡實掃如果只查池中的寫法，
會漏掉「MB 用羅馬字建檔、我們用漢字提案」造成的假陰性。

## 4. **MB 的 `first-release-date` 對「數位再發整批建檔」的藝人不可信**

江利チエミ 名下 60 個 RG，其中 **20 餘筆的 `first-release-date` 是 `2026-01-10` 或 `2026-01-11`**
（《チエミは歌う チエミ・デラックス》《チエミのクリスマス》《チエミ・オン・ステージ》等 1950–60 年代的盤全在裡面）。
那是數位再發被整批建檔成同一天，不是發行日。

**裁定：這一型條目一律不釘。** 本批只取她 `1958-11` 那筆有正常日期的《チエミの民謡集》。
**形狀要記著**：「一位藝人名下十幾二十筆 RG 共用同一個近期日期」＝ 批次匯入，不是發行事實；
第 91／95 條（rgMbid 是身分鍵不是年份來源）在這裡是保命的——身分還能用，年份不能用。

## 5. **收錄基準：「全曲集／ベスト」型一律不收，即使它照第 167 條可以當一般 Album 寫**

第 1 條的結論是這一型**技術上**可以照一般 Album 寫。但池中**已經有四張同型**
（森進一《森進一全曲集》、北島三郎《北島三郎全曲集》、フランク永井《フランク永井全曲集》、五木ひろし《五木ひろし全曲集》），
再收就是 §5.6 明令不收的「氾濫的 greatest-hits 重複包裝」。

**裁定：本批只收 `primary-type=Album` 且 `secondary-types` 為空的原盤**（44 張全部符合）。
這條同時解釋了為什麼北島三郎、水前寺清子、千昌夫、川中美幸、伍代夏子、美川憲一、山本譲二
這些 MB 上有幾十筆條目的藝人，本批一張都沒收——**他們的條目全是這一型。**

## 6. **合唱盤／拼盤不收；樂隊伴奏的合掛名可以收**

- **不收**：八代亜紀《二人の旅路》1974（artist-credit 實為「石原裕次郎／八代亜紀」，雙主唱對唱盤）、
  森進一・青江三奈《夜と恍惚とため息と》1968（同一個 RG 同時掛兩人，且 `secondary-types` 含 Compilation）、
  ちあきなおみ《ミコーなおみーマリ》1970（三人拼盤）、
  細川たかし名下的《三橋美智貴 民謡のこころ》2010（MB 掛在他名下，實為他人作品）。
- **收**：江利チエミ《チエミの民謡集》1958，credit 是「Chiemi Eri, 見砂直照と東京キューバンボーイズ」。

**判準：兩個主唱各唱各的 → 不收；一個主唱＋一個伴奏樂隊 → 收，樂隊寫進 `queryAlias` 與備註。**
（八代亜紀那張如果收，卡片掛名要嘛掛錯人、要嘛得新開一個對唱掛名，兩種都比不收貴。）

## 7. **`status` 未填與 Pseudo-Release：可以收，但不得當背書**

第 43／57／65／78 條要求「考古再發只有標 Official 才算背書」。本批逐筆查 release 的 status：

| 情況 | 卡 |
|---|---|
| 轄下唯一 release **status 未填** | 八代亜紀《舟唄》1979、坂本冬美《祝い酒》1988 |
| 轄下含 **Pseudo-Release** | 小林幸子《おもいで酒》1979、梶芽衣子《銀蝶渡り鳥》《はじき詩集》《やどかり》 |
| 轄下**只有 XW（無 JP 實體）** | ちあきなおみ《もうひとりの私》1972 |

**裁定：三種都收，但已在各卡 `risk` 明令「不得採為再發背書」，並指出配對要避開哪一筆 release。**
理由是這些都是有實體唱片、只是 MB 的 release 層建檔不全——不是身分有疑義。

## 12.（收尾補記）**廠牌欄不能靠藝人的「所屬公司」推，逐張回問 `release?release-group=…&inc=labels` 抓到三個錯**

44 張全部回問過 `release?release-group=<id>&inc=labels&limit=100`，拿 JP／Official 那筆的 label-info 當廠牌。
**用「這位藝人在那個年代屬於哪家公司」推出來的答案，錯了三張：**

| 卡 | 推的 | 實際（MB label-info） |
|---|---|---|
| 森進一《悲しい歌が流行ります》1992 | 日本コロムビア | **日本ビクター VICL-320**（他 1975–1988 在ワーナー・パイオニア，1990 年代才回ビクター——「回哪一家」猜錯了） |
| 五木ひろし《流転》1971 | 徳間音楽工業 | **ミノルフォン KC-7002**（徳間旗下的廠牌，不是母公司掛名） |
| 雪村いづみ《スーパー・ジェネレイション》1974 | 日本コロムビア | **Alfa ALFA-1001**；日本コロムビア COCA-12155 是 **1994 年的 CD 再發**——日文維基寫「コロムビア」指的是再發那一版 |
| 江利チエミ《チエミの民謡集》1958 | 日本コロムビア | **キングレコード LKF-1011** |

另外兩張的廠牌是**子廠牌**，不是母公司：石川さゆり《天城越え》是 **DENON AF-7422**（コロムビア旗下）、
ちあきなおみ《港が見える丘》是 **INVITATION VIH-28206**（ビクター旗下）——
這兩張如果只寫母公司，簡介裡的廠牌沿革就會說不通。

**裁定：`label` 欄一律填 MB 的 JP／Official release 的 label-info（含 catno），不填推測的母公司名；
母公司與子廠牌並存時寫成「母公司／子廠牌（catno …）」。**
順帶：這一輪也把 44 張的 catno 全部補進 `label` 欄了，建卡與封面配對可以直接用。
