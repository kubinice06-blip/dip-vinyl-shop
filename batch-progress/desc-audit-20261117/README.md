# 一般卡簡介品質抽查（2026-11-17）

店主看到林強《驚蟄》的簡介（整段只講軌序、曲名印法、DVD 附碟、最長一軌 7:08）：「這介紹跟沒介紹一樣，這到底是什麼專輯？故事在哪？概念在哪？我看到不只一張這樣敷衍的介紹了，檢查是不是很多都這樣。」

- 根因（《驚蟄》）：c89 批研究層只查 MusicBrainz／Discogs，facts 全是曲目表、曲長、盤號；鉤子層再拿「第 2、3 軌拆成兩段」當鉤子。研究薄＋鉤子公式，與 apex-desc-base「為什麼改」講的同一個問題。
- 全卡池 22,302 張現行簡介從 KV 讀出（`dump-descs.mjs`，desc2 21,764、desc4 538）。
- 隨機抽 400 張一般卡（排除頂點卡，種子 20261117），兩支 Sonnet 照 apex-desc-base 第一節判（第 2 條改為「讀完要知道是什麼、誰做的、故事或概念、為什麼值得聽」），結果 `sample-400.json`：
  - **severe 67（17%）**：和《驚蟄》同類，主體是細節雜項、沒故事沒聲音。
  - **rewrite 194（48%）**：冷知識開頭、沒有聲音描述、細節雜項過半等。
  - **keep 139（35%）**。
  - 命中最多：第 3 條沒有聲音描述、第 1 條冷知識開頭、第 4 條細節雜項。
- 依來源：desc-restyle c80–c139 批最糟（22 張中 severe 14）；10 月起新上架的卡（add-）也有 severe 16%、rewrite 56%——一般卡現行寫作規則（writer-base 鉤子公式）仍在產生這種稿。
- 推估全卡池一般卡約 21,600 張：severe 約 3,600、rewrite 約 10,500、keep 約 7,500。
