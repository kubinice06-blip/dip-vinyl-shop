# 寫作層補充（s10：流亡 ad-19、ad-20）

先讀 `prompt-writer-extra-s7.md`（流亡節）與 `prompt-writer-extra-s8.md`，照做。另加：

- **前兩句要讓讀者知道它憑什麼值得找來聽**：為什麼少有人聽（私壓、壓量、卡帶／demo、地方小廠、沒再版、樂團早散）＋為什麼值得聽（後來哪個廠哪年重新發行、被誰點名或收錄、它做到了什麼）。兩半都要是研究稿 facts 裡的事實；沒有評價就寫它做到的具體事實，不硬擠。
- 不寫遊戲用語（頂點、流亡、殿堂、異端、入選）。
- **出處只放 facts，不寫進簡介**：不寫「某廠形容」「某樂評說」「有評論認為」「據團員受訪」；單一來源的評價用「被視為」，不用「常被視為」（「常」要兩個以上具名來源）。
- **Discogs 收藏統計一律寫質性**（「在收藏圈想找的人遠多於手上有的人」），不寫人數、倍數；唱片行標價、售完等當下快照不寫。
- 只查過單一版本的寫「沒有再版紀錄」，不寫「之後沒有再版」。
- coverage sound 為 none 的卡，不從曲名、封面、風格標籤推音色；只寫編制、分工、曲長、結構。風格標籤只准寫成「路數偏某某」。
- 年份兩說時寫年代（「1980 年代初」）或不寫年份。
- 字數 200–280（`Array.from(desc).length`），先量再改；超字先刪次要人名與冷知識，不砍聲音段。
- **暫存檔一律放你自己的子目錄**：`/tmp/claude-0/s10-{BATCH}-w{N}/`（s9 兩支寫作代理共用檔名互蓋過）。
