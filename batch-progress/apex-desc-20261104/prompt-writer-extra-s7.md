# 寫作層補充（s7：異端 ad-13、流亡 ad-14）

**前兩句要用事實講清楚它憑什麼是這一級**（apex-desc-base 第三節表格；不寫「頂點」「異端」「流亡」「入選」等遊戲用語）：

- **異端**：第一、二句講**極端在哪裡**（長度、音量、噪音、編制、手法——用研究稿裡的具體數字與做法），以及**為什麼這份極端被認真看待**（開了哪條路、當時的反應、後來的評價）。
- **流亡**：第一、二句講**它是什麼、為什麼少有人聽**（私壓、壓量、地方發行、沒再版、樂團早散），以及**為什麼值得聽**（後來被誰重新發行或點名、收藏圈怎麼看、它做到了什麼）。沒有評價就不寫評價，寫流通與再發現的事實。
- 再版廠文案的形容詞（「失落的傑作」）不寫；廠名與再版年份照寫是事實。
- 出處不寫進簡介（不寫「某廠形容」「某樂評說」）。
- 聲音段照舊最具體。異端與流亡卡讀者多半沒聽過，寫出樂器、音色、手法、結構。
