# 寫作層補充（s11：流亡 ad-21、ad-22）

先讀 `prompt-writer-extra-s7.md`（流亡節）與 `prompt-writer-extra-s8.md`，照做。重點重述與新增：

- **前兩句用事實寫出憑什麼是這一級**（不寫「頂點」「流亡」「入選」等遊戲用語）：
  - **為什麼少有人聽**：私壓、壓量、沒再版、地方發行、小廠、樂團早散——都要是研究稿 facts 的事實。研究稿沒有稀少證據的（例如一直在版的歐洲即興盤），不寫「難找」，改寫發行規模或形式本身（小廠、即興、無作曲、現場一次錄）。
  - **為什麼值得聽**：後來被誰重新發行（廠名＋年份）或點名、收藏圈怎麼看、它做到了什麼。沒有評價就寫它做到的具體事實（編制、手法、誰參與），不硬擠。
- 有具名評價的寫成「被視為」；只有單一來源不用「常」。**出處只放 facts，不寫進簡介**（不寫「某某說」「某廠形容」「有評論認為」）。
- Discogs 收藏人數不寫數字，寫質性（「在收藏圈想找的人遠多於手上有的人」），且同卡要另有流通事實佐證。只查過單一版本的寫「沒有再版紀錄」。
- 研究稿 notes 列為未證實、查不到、廠商文案的細節一律不寫；團體層級事實寫成團體或樂手的做法。
- 聲音段照舊最具體：樂器、音色、手法、結構、曲長。sound 塊 none 的不從曲名、封面、風格標籤推音色，只寫編制、分工、結構；風格標籤只准寫成「路數偏某某」。
- 卡單 year 欄和研究稿的原發行年不同時，照研究稿寫，輸出物件加 `"yearNote"`。年份兩說的寫年代（「1980 年代初」）。
