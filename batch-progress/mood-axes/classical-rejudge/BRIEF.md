# 古典／前衛偏誤重判工單（2026-10-29）

店主實機轉到 **Jonathan Harvey《Tombeau de Messiaen》**（鋼琴對錄音帶的頻譜作品，閃爍、密集、無調）被歸在**平靜**，店主：「這張不是平靜的耶，解析一下標準，再抓遺漏的。」

## 為什麼會錯（同形狀的卡就是你這份清單）

- 模型評分給它 2.4（靜）。10-23 有一輪「撤回推力」規則：**沒有鼓在推就不算躁**，把一批現代音樂、音塊、噪音的能量撤回靜。
- 同一天稍晚店主親手試聽，推翻了那條：**能量是「張力、不安定」，不是「有沒有鼓」**。不和諧、尖、不可預測、讓人坐不住的，再安靜也是躁（Feldman《Rothko Chapel》、Ligeti、Penderecki、Kancheli 都被店主拉到冷冽）。
- 之後的體感重判只改「差 0.4 或換格」而且「拿不準就不改」，10-27 的曲風偏誤重判只掃了爵士與中日韓文字的卡。**古典、現代音樂、電子噪音、殘留的自由爵士從沒被專門重看過。**

這份清單：目前在「靜」那一半（x < 3.0）的 ① 主曲風古典（全部子類）② 電子的 noise／industrial／glitch／concrete ③ 自由／前衛爵士 ④ 被「撤回推力」拉回靜的卡。店主親點過的已排除。

## 標準

**先完整讀 `batch-progress/mood-axes/felt-rejudge/BRIEF.md`（三軸新定義＋店主親手點的校正樣本）**，再讀 `batch-progress/mood-axes/bias-rejudge/BRIEF.md` 的能量段。照那兩份，這批特別注意：

### 能量：整張專輯的體感，是神經被挑起來，還是被安撫、往下拉

**躁（就算很安靜、沒有鼓）**：
- 無調、序列、頻譜、音塊、微分音、尖銳的弦樂泛音、突兀的動態、不可預測的結構——聽了會緊繃、坐不住。Harvey、Ligeti、Penderecki、Xenakis、Stockhausen、Boulez、Berio、Nono、Lachenmann、Ferneyhough、Saariaho（多數）、Murail、Grisey、Scelsi（多數）、Carter、Schoenberg／Berg／Webern 的無調與十二音作品、Varèse、電子原音與錄音帶音樂（musique concrète、GRM、WDR）→ 躁，通常**冷冽**（尖細）或**暴躁**（厚重的音塊、大編制）。
- 戲劇性、壓迫感強的大編制：表現主義歌劇、Shostakovich 的戰時交響曲、Bartók《藍鬍子城堡》、Weinberg、大合唱音牆（Carmina Burana、Axion Esti 店主判暴躁）→ 躁＋重。
- 店主例：Feldman《Rothko Chapel》冷冽、Kancheli《Vom Winde beweint》冷冽、Bartók《弦樂、打擊樂與鋼片琴》冷冽、Shostakovich 8（Mravinsky）暴躁、Mica Levi《Under the Skin》暴躁、Galás 暴躁。
- 有推進的極簡主義（Reich、Glass、Adams、Riley《In C》、Nyman、Louis Andriessen）：被脈動推著走 → 躁（旋律清楚的偏暖＝雀躍，冷硬的＝冷冽）。
- 噪音、harsh noise、工業：刺耳、尖銳、攻擊性的 → 躁（Merzbow、Masonna、Whitehouse、Throbbing Gristle 多數、Einstürzende Neubauten 早期）。
- **自由爵士、前衛爵士、無調即興：一律不在靜**（店主原話「絕不輕鬆」）。

**仍然是靜**（不要矯枉過正）：
- 調性清楚、抒情、平穩的古典：巴洛克慢板與大部分鍵盤組曲、古典時期室內樂、浪漫派夜曲／間奏曲／藝術歌曲、印象派鋼琴、Satie、Fauré、聖詠與文藝復興複音。
- 神聖極簡與冥想型：Pärt（tintinnabuli）、Górecki《第三號》、Tavener、Vasks、Silvestrov、Hildegard、Max Richter、Ólafur Arnalds、Nils Frahm、Jóhannsson（店主：《Arrival》頹靡）、Harold Budd（店主：頹靡）、新古典鋼琴。
- 極慢、持續、把人包住往下沉的：drone、Sunn O)))（店主：頹靡）、慢速的 dark ambient、Feldman 晚期極長的作品**只有在你確定它整張是靜止懸浮、毫無不安時**才留靜（店主把《Rothko Chapel》判冷冽，所以 Feldman 預設往躁）。
- 店主例外：Jonny Greenwood《There Will Be Blood》**平靜**——持續、懸浮的弦樂音塊，沒有突兀爆點。慢而懸浮的音塊可以是靜；**閃爍、密集、尖銳、突兀**的才是躁。這是判斷關鍵。
- 浪漫派大型交響曲看整張：抒情田園、慢板為主 → 靜；戲劇性、悲劇性、高潮迭起（Mahler 6、Tchaikovsky 4、Bruckner 大段銅管）→ 躁（通常重）。

### 色溫、質地

照 felt-rejudge 的定義。
- 無調、頻譜、音色撐場、旋律不明 → 冷（**不管樂器多溫潤**）；調性清楚、唱得出來 → 暖。
- 尖、細、高頻、稀疏、有空氣（獨奏鋼琴的高音閃爍、弦樂泛音、電子尖音）→ 輕；厚、密、低沉、大編制、合唱音牆、低頻 drone → 重。

## 怎麼改

八格＝能量（躁 ≥3.0／靜）× 質地（重 ≥0.5／輕）× 色溫（暖 ≥0／冷）：
放鬆＝靜輕暖、平靜＝靜輕冷、恍惚＝靜重暖、頹靡＝靜重冷、雀躍＝躁輕暖、冷冽＝躁輕冷、沸騰＝躁重暖、暴躁＝躁重冷。

1. 每張**整張專輯**明確回答三個問題：躁還是靜？重還是輕？冷還是暖？得出它該在的格。
2. 該在的格跟目前的格（`c`）不同 → 改，換邊的軸離門檻至少 0.3（判躁 ≥3.3、判靜 ≤2.7、判重 ≥0.8、判輕 ≤0.2、判暖 ≥0.3、判冷 ≤−0.3）；沒換邊的軸照抄原值。
3. 格子沒錯就不輸出。
4. **不要「拿不準就不改」**：你認識這位作曲家／演出者／藝人、能判斷整張的體感，就明確選邊。古典唱片看「收了哪些曲目」（專輯名多半就是曲目），同一作曲家的不同作品可能落不同格。只有完全不認識、也無從由作曲家、年代、子曲風推斷的，才不改。
