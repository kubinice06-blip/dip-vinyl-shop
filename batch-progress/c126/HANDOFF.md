## 五、⚠ 一個工具 bug 造成的假結論（裁定 277）

主線把 `recover-unavailable.mjs` 的店面碼串成一個逗號字串
（`c126 tw,hk,sg,...` 而不是 `c126 tw hk sg …`），
於是每次請求都打到不存在的 country。**Apple 對不存在的 country 不回錯誤、回合法的空結果**，
報告因此寫著「**14 張全部 0 個候選**」——跟「這 14 張真的沒上架」長得一模一樣。

**重跑後 13/14 都有候選。** 腳本已加店面碼檢查（`/^[a-z]{2}$/`，不合法就 exit 1）。
**通則：命中率是 0/N 而不是 3/N、5/N 時，先手動打一次 API 確認管線是通的，再相信那個 0。**
