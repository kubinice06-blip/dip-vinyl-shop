  1. **立第 156 條：「兩個來源都這麼說」有時是同一個來源說了兩次。**
     Allen Clapp 那張的年份表面上 3 比 3，但**維基那句的引註正是同一個 AllMusic 頁**
     ——實際是 3 比 1。**年份分歧要數的是「獨立來源」不是「條目數」**；
     維基的某一句要算成獨立的一票，必須點開行內引註確認它引的不是已經在名單上的來源。
     **維基是索引，不是來源。**
  2. **立第 155 條，記我自己的派工錯誤**：我把 c-84 研究 b 的交件回報整理成「本批重點」，
     貼進了 **hook a 與寫作 a 兩份派工信**——那六張碟全在 b 組。
     沒造成損害，因為兩支代理都依第 142 條以自己輸入檔的 `researchNotes` 為準而忽略了它。
     **交件回報是按組寫的，派工信也是按組發的，但兩者的「組」不一定是同一個。**
  3. **第 140 條最典型的一張在這批**：Crayon《Brick Factory》的 2014 版「**也是 14 軌**」，
     卻抽掉一首換上另一首——**軌數相同不代表曲目相同**，只比軌數會直接放行。
  4. **同編號同年同廠牌、黑膠 8 軌／CD 10 軌**（Lorelei，SLR 44），兩庫都同時記著兩個數字
     → 依第 141 條兩個都不填、**只能按載體分開講**。本批同形共五張。
  5. **hook 層退回十七則自算錯的候選**（a 組單組十四則，本線最多），形狀分六類，
     其中三則是**誤讀來源**：Discogs **圖片的拍攝說明**被讀成唱片設計、**欄位裡的底線**被讀成

     還有一則「四種封面配色」——**原文是 including，列了四種不等於只有四種**。

     **b 組寫作層各自重數過那兩處、兩處都成立。**
