前三輪研究代理全數卡死：兩輪被容器重啟砍掉，第三輪六支在第一個 Bash 指令就停住 25 分鐘（推測卡在背景代理看不到的權限確認）。所以：

1. **不要 `cd` 到工作目錄以外**（包括 `/tmp`）。所有指令都從 `/home/user/dip-vinyl-shop` 跑，不寫 `cd`。
2. **Bash 指令保持單純**：一次一個 `curl -s -m 20 …` 或 `node <腳本>`；不要定義 shell 函式、不要長串 `;` 串接、不要 `python3 -c` 管線。要解析 JSON 就把腳本寫成檔案（放在 `desc-tools/batches/research/tmp-<批>-<組>/`，交件前刪掉）再 `node` 執行。
3. 網頁優先用 **WebFetch**（維基 API 常回 429）；MB／Discogs／iTunes API 用 curl。
4. 讀完規範就開工，**每做完 1 張立刻寫輸出檔**；輸出檔已有內容就從沒做的那張接續。
