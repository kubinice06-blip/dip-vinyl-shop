## 第 1202 條（同批，**重要；新立，把第 1146／1173 條的界線操作化**）：**「先前發行過」之後的那一問，要問的是「那次發行的目錄號在不在本線掃的 Blue Note 目錄裡」**

第 1173 條把判準寫成兩句：
> **(甲) 沒發行過 → 收，`year` ＝ 首次商業發行年。**
> **(乙) 有 → 再問一句：「先前那次發行在本線的任何清單／池中另有身分嗎？」有 → 退（重複）；沒有 → 收、`year` 取那次的年。**

**本批一次撞到 (乙) 的兩邊，而且同一批裡三比一，剛好可以把「另有身分」這五個字定義死：**

| | **退（母體在 Blue Note／Liberty-UA 家族的號段裡）** | **收（母體在真正的他廠號段裡）** |
|---|---|---|
| 例 | **《Curtain Call》**母體 `BNJ 61006`（Blue Note Japan, 1984）<br>**《70th Birthday Concert》**母體 `SS 19000`（Solid State／United Artists, 1970）<br>**《Wailing With Lou》**母體 `BLP 1545`（Blue Note, 1957） | **《Live at the Village Vanguard》**母體 `GW-3006`（**Concord Jazz／The George Wein Collection**, 1985） |
| 母體在不在列舉檔掃的目錄裡 | **在**（Blue Note／Liberty／UA／Solid State 都屬本線期一至期二的範圍） | **不在**（Concord 的自家號段，列舉檔只掃 Blue Note 目錄） |
| 退掉會怎樣 | **不會消失**：母體本來就該以原盤年建卡，寫進資料庫缺口即可 | **整張碟從管線消失** |
| 判定 | **退**，母體進缺口表 | **收**，`year` 取母廠首發年、`label` 寫母廠 |

**→ 判準改寫成三句（覆蓋第 1173 條的兩句版）**：
> **(甲) 這批錄音先前沒有以商品形式發行過 → 收，`year` ＝ 首次商業發行年。**
> **(乙) 發行過，而且那次發行的目錄號屬於 Blue Note／Liberty／United Artists／Solid State 家族 → 退；母體以原盤年寫進資料庫缺口。**
> **(丙) 發行過，但那次發行在真正的他廠（Concord、Palo Alto、Artalent……）→ 收，`year` 取他廠首發年、`label` 寫原廠、`risk` 註明 Blue Note 版年份**（簡報 §三-3 那條）。

⚠ **(乙) 裡特別要記 Solid State**：它是 United Artists 的爵士子廠、1966–70 年與 Blue Note 同一個母公司，
**c-152 a 第 1141 條退《Togo Brava Suite》時用的就是同一個理由（母體 1971 UA 雙 LP）**——**本條只是把它從個案變成規則。**
⚠ **(乙) 與第 1173 條的 `Rachelle Ferrell —《First Instrument》` 不衝突**：那張的母體是 **Somethin' Else 的自家號 `TOCJ-5520`**，
**Somethin' Else 雖然算 Blue Note 的子廠牌（第 906／1118／1155 條），但它的自家號段不在列舉檔掃的範圍內**——
**「算不算子廠牌」與「號段在不在列舉範圍內」是兩件事，收退看後者。**

## 第 1204 條（同批）：**《The Palo Alto Sessions 1981-1985》是本段第一張「MB `secondary-types` 空、但它確實是合輯」的碟**

## 第 1233 條（同批，**重要；為第 1202 條補上第四句 (丁)**）：**母體在他廠、但先前那次發行只是「部分」或「不同形狀」的，`year` 取本次完整發行的年，不取他廠首發年**

第 1202 條 (丙) 寫的是：**發行過、但母體在真正的他廠 → 收，`year` 取他廠首發年。**
**它的原型是 a 組的 Petrucciani《Live at the Village Vanguard》——那張是「同一張碟、同樣的八軌、1985 年就在 Concord 出過完整的雙 LP」**，
