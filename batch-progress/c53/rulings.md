# c-53 蘇聯／俄語圈：主線裁定（2026-09-01）

---

## 1. 年份政策：磁帶原盤即算原盤　（我給的規則自相矛盾，這裡定案）

策展代理指出我給的兩條硬規則在蘇聯的情境下打架：

- **規則 4** 說「一律以該作品最早的**正式發行**為準」
- **規則 2** 說「重發的 release-group 會蓋掉原盤年份，`year` 欄填**原盤年**」

蘇聯 1980 年代的地下搖滾多半靠自錄卡帶（магнитиздат）流通，第一次帶廠牌的發行
往往是十幾年後的 CD。照規則 4，Аквариум《Табу》要填 **1994**（Триарий CD），
而原帶是 1982——那正是規則 2 明文禁止的錯誤。20 張裡有 14 張有這個落差，
最極端的是 Гражданская оборона 兩張（1988／1989 母帶 → 2001 年 CD，落差 13 年）。

**裁定：`year` 填該作品原始問世年，磁帶原盤即算原盤。** 規則 4 作廢，規則 2 為準。

理由不只是「兩條規則要挑一條」。卡池的年份欄意思是**這張唱片什麼時候來到世上**，
不是**哪一年有廠牌把它變成商品**。магнитиздат 不是預備動作、也不是私錄流出，
它就是那個體制下的發行方式——那正是這條線值得收的原因。填 1994 會讓一張
1982 年的唱片在卡池裡排到 grunge 之後，那是錯的。

策展代理已經在每張的 `risk` 寫明「卡帶年 → 首張帶廠牌發行年＋廠牌＋編號」，
落差資訊沒有丟失，行文可以用。**這條同樣適用於 b 組的 бард 線**
（Высоцкий 生前幾乎沒有在蘇聯正式發行過專輯）。

只有 3 張原盤即正式發行：Аквариум《Равноденствие》、Машина времени《Реки и мосты》、
Алиса《Шестой лесничий》（皆 Мелодия）。

## 2. 掛名用西里爾，但 Наутилус Помпилиус 是例外——這個例外要往下游傳

抽驗定的規則是「一律用西里爾原文」，46 筆候選查詢裡 41 筆西里爾直接命中，規則成立。

**但有一個藝人違反通則**：MusicBrainz 的 Наутилус Помпилиус 藝人條目掛的是
**拉丁名 Nautilus Pompilius**（`247efe0f-80f1-477c-a4a0-b5cb1b8c832e`），
用西里爾團名查 release-group **零命中**，那兩張是改用 artist MBID browse 才拿到的。

**裁定：卡片掛名仍用西里爾（與卡池的原文字慣例一致），但這兩張必須帶一個
下游查詢用的別名。** 封面（Bandcamp／Spotify／CAA）、評分、試聽三條線
如果照西里爾掛名去打 API 會整個落空——這與 c-TW3 那次「只試一種寫法就誤判成
目錄裡沒有」是同一個錯，只是換了語言。

具體做法：這兩張的卡片加 `queryAlias: "Nautilus Pompilius"`，
探測腳本優先用 rgMbid（CAA 本來就以 MBID 為鍵，不受影響），
需要打字串搜尋的 API 則同時試西里爾與別名。

## 3. Гражданская оборона 兩張都有同名雙胞胎 release-group

《Всё идёт по плану》另有 1992 年的 `14095de2…`（Album/**Compilation**）、
《Русское поле экспериментов》另有 1989 年的 `075d7d54…`（Album/**Compilation**），
兩組的 search score 都是 100——**只看分數會抓錯，而且會同時錯年份與 release type**。

正確的是 `9043b500…` 與 `bd266079…`（策展代理已釘）。

**裁定：這正是 c-52 收斂器那個 bug 的同一個形狀**（合輯懲罰沒生效，
把 Compilation 當正規盤收）。c-52 已修好的 `consolidate.mjs` 對 Compilation
的扣分邏輯，c-53 開跑時要沿用，不能重寫一份沒有那個保護的。

## 4. 沒提但值得記錄的取捨

策展代理列了「查過但因資料不足而沒提」的名單，其中三筆的理由值得留著：

- **Вежливый отказ《Опера-86》**：MB 標題的連字號實測是 **U+2010**（非 ASCII），
  正好踩 `chk-prop.mjs` 的反模式（c-50 踩過）。要收得先裁定標題正規化寫法。
- **Сектор Газа《Колхозный панк》**：兩個 release-group，1989-06 那個被標
  **Album/Demo**、1992 才是 Album，原盤身分歧義大。
- **Крематорий《Иллюзорный мір》**：MB 標題用改革前正字法「мір」（現行是「мир」），
  拼寫比對風險高。這與印尼 1972 拼寫改革是同一類問題，只是俄文的改革在 1918 年。

另有十張「資料齊全、純因名額割捨」的（Наутилус《Невидимка》、Аквариум
《Дети декабря》、Кино《Это не любовь》、Браво、Чайф、Агата Кристи 等），
要擴編可直接補，不必重查。

**Машина времени《В добрый час》(1986)** 特別記一筆：那才是樂團第一張官方 LP，
但 MB 標為 Album/Compilation，要收就得走 §5.6 舉證。策展代理改收同期的
《Реки и мосты》(1987) 以免在策展層製造合輯例外——這個取捨我同意，
但《В добрый час》值得日後單獨處理。
