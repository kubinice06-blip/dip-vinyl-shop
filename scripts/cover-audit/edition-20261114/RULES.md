# 主站封面版本清查：判定規則（2026-11-14，店主：「有些封面用成了 CD 版或其他特別版……我只要正常版就好」）

## 背景
- 主站卡片封面讀 Firestore `card_catalog/<docId>.coverUrl`。多數是 `coverartarchive.org/release-group/<rg>/front`，CAA 會回該 release-group 底下**任意一筆**有圖的 release，常常抽到 CD 重發、日本帶側標版、特別版。
- 已知壞例：達明一派《石頭記》抽到 K2HD 特別版（黑底橫條＋原封面縮小內嵌）；Argerich《Rach 3》抽到 2001 年重發 CD（封面畫一張光碟，原封面縮成小圖）。

## 對照表上的候選圖
- **NOW**：現在主站顯示的圖（CAA 實際服務的那筆 release）。
- **ALT…**：同一個 release-group 裡其他有圖的 release（標日期／國別／格式）。換這種最省事（不用登記）。
- **DG**：Discogs master 的主圖（通常是原版首發）。可當替換來源，但要登記名冊。
- **WP**：維基百科條目的封面圖。**只當「原版長什麼樣」的參考，不能拿來當替換圖。**
- 參考圖（DG、WP）可能抓錯專輯（同名、精選、單曲）；看標題與年份，不像就忽略它。

## 判定（每一組給一個）
- `keep`：NOW 就是這張專輯通行的原版封面設計，畫面乾淨。後來的重發只要**視覺一樣**就算（唱片公司小 logo、目錄號、Stereo 字樣這種原版本來就有的不算問題；稍微裁切、顏色略不同也算一樣）。
- `alt:<tag>`：NOW 有問題（見下），而某個 ALT 是乾淨的原版設計 → 換那個 ALT。
- `dg`：NOW 有問題，沒有可用的 ALT，而 DG 是乾淨的原版設計（不是褪色歪斜的實拍、不是帶側標的日版）→ 換 DG。
- `need`：NOW 有問題，但表上沒有可用的替換圖 → 交給找圖。
- `unsure`：看不出 NOW 是不是原版（參考圖缺或對不上，而你也不認得這張的原版）。

**「有問題」的 NOW**（任一即算）：
1. **不同的設計**：跟原版（參考圖或你確知的原版）是不同的封面——重發另做的設計、系列套版（例如「The Legacy of the Blues」「Original Jazz Classics」整片重排的模板、精選系列框）、別國的另一套設計（不是通行那套）。
2. **原封面被縮小內嵌**在另一個框／底色裡，或畫上光碟、外盒。
3. **重發才有的字樣或標記印在封面上**：K2HD／XRCD／SHM-CD／Blu-spec／24bit／Remastered／Deluxe／Expanded／Anniversary／Collector's、系列 logo 方塊（如 OBC、OJC、RVG Edition、Blue Note Tone Poet 的大標）等**明顯加上去**的東西。
4. **實物照片**：拍到側標（obi）、貼紙、塑膠膜反光、破損、歪斜，或掃描嚴重褪色模糊。
5. **根本不是這張專輯**（別張、精選、單曲、現場盤）。

**取捨**（店主 2026-08-30 規則）：
0. 封面真的分岔時，取**廣為流傳、大家認得**的那一套。
1. 同一套視覺內，以**發行國**的版本為主。
2. 年代越早越好。
3. 太模糊、褪色、實拍歪斜的，退而取同視覺中最清楚的。
NOW 跟替換圖是同一套設計、NOW 只是較晚但乾淨 → `keep`（這次只修「不是正常版」的，不為了年份更早而換）。
