## 規則（規則卡六行，D §5 逐字）

1. 每張專輯有經典／冷門／硬蕊三個星數。
2. 每一手，你和他各暗中挑一張專輯、一個屬性，同時亮出。
3. 冷剋經、經剋硬、硬剋冷：剋中，就用你那個屬性的星數扣他聲望。
4. 被剋的一方高 2 星以上，剋不動，改成比星數。
5. 沒有相剋就比星數，高的扣差額；一樣大不扣。
6. 提示會暗示他這手的打算，但有些人會唬你。王牌 7 星、不會被剋，一場用一次。六手內沒分出勝負，比剩下的聲望。

- **手牌**：包包裡隨機抽 3 張＋王牌。點封面＝選這張、自動選最高那一顆星；點別的星換屬性；只有「丟！」會出手（再點已選的星不會丟）。長按封面＝唱片資訊、試聽。
- **他**：也有暗手 3 張，照原版出招難度挑（第 1、2 位 easy、第 3 位與菁英 normal、藏家 hard，序章男子 easy；你落後時他會鈍一點）。他的封套揭曉前一直蓋著。
- **提示**：每手一句店裡的動作或一句話，藏著關鍵字（名盤／紀念版／大家都聽過＝經典；絕版／白版／沒人聽過＝冷門；噪音／聽不懂／實驗＝硬蕊），畫面上不寫屬性名。
- **唬人**：照機率（序章男子老實；一般客人約八成照實、菁英約七成、藏家約六成）。唬你的時候他出「剋掉你剋提示那招」的那色；王牌那手一定照實。誠實度**不顯示**（店主：看了很煩），從結果句「他唬你！」自己體會。
- **結果句**：揭曉後一句講清楚，順便教關鍵字，例：「冷門剋經典，命中！他 −4」「冷門剋經典，但他高你 2 星以上，剋不動。比星數，你 −3」「他唬你！『紀念版』是經典，他出的是硬蕊。你 −4」。
- **六手上限**：六手打完比剩下的聲望，一樣多算你贏。整場最後一手播**整場贏家**的那張當勝利曲。
- **教學**：「▶ 接受對決（看向老闆）」＝老闆帶的六手（同色比星數、冷剋經、經剋硬、硬剋冷、差 2 星剋不動、王牌），依你挑的王牌三種講法；「▶ 接受對決（手伸進袋子，準備出招）」＝直接開打。

## 一晚

```
21:30 推門 →（第一晚）序章男子 → 22:00 → 22:40 → 23:20（一般客人）→ 00:10 菁英 → 02:00 傳說藏家 → 打烊
```

- **序章**：猜今晚那張 → 三張王牌挑一張 → 老闆送四張 → 特價區 6 挑 3（免費）→ 八張放上櫃檯、飛進包包 → 男子進門、後走道對峙 → 接受對決。打贏：他走出門、地上留下 Fishmans《Long Season》（撿起面板沒有旁白）→ 配件三選一 → 今晚第一位客人推門進來。
- **今晚來客**：一般 6 抽 3、菁英 2 抽 1、藏家最後；日期種子。店內底部一條，五顆頭像、錢、包包、配件。
- **贏了**：他丟過的唱片挑一張收進包包（最多 8 張）；菁英與藏家可以改拿配件。**輸了**：每晚一次老闆說情，同一位重打；序章男子輸了一律免費再一場。
- **再來一夜**：挑王牌 → 走到特價箱挑三張 → 今晚來客（包包 7 張；身上的配件帶過來）。

## 除錯旗標

- `?seed=20261106`：指定日期種子。`?fast=1`：動畫 4 倍速。`?strict=1`：走不到就丟錯（e2e 用）。
- `?debug=1`：開 `window.__lab`
  - `__lab.autoplay('thoughtful')` 自動打完這場；`{until:'end'}` 一整晚；`{animated:true}` 用盤面真的點
  - `__lab.skipTo(3)` 跳到今晚第 4 位；`__lab.forceWin()`／`forceLose()`；`__lab.force({kind:'counter',toE:3,toP:0})` 之後每手都照這個結果（`null` 取消）
  - `__lab.money(n)` 設錢；`__lab.shop()` 今晚的貨；`__lab.timeline()` 逐句執行器的時間軸；`__lab.stageAction('crate:jazz')` 模擬點店裡的東西
  - `__lab.duelLab.start({enemy:'copycat', seed:7, hp, ehp})` 直接在對決畫面開一場（打完停在大章、不結算）；`duelLab.setNext({i,attr})` 他下一手照這個出（e2e-duel 用）
