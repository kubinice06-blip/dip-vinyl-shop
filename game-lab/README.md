# 品味對決・試做版 v4（game lab）

以 `roguelike.html` 的卡牌遊戲為基底的試做。獨立頁面，**沒有動到正式頁**，也沒有寫 Firestore／KV（封面、試聽、平台連結都在建置時烤進 `cards.js`，`tools/bake-cards.mjs` 只讀 Firestore 公開 REST）。

- 網址：`/game-lab/`（本機：在 repo 根目錄 `python3 -m http.server 8765`，開 `http://localhost:8765/game-lab/`）
- 手機直式優先。驗收尺寸＝**390×664、375×548、430×932、360×640**，四個都不用捲。
- 存檔只寫 `localStorage['dipGameLab_v1']`（存檔版本 6＝從唱片櫃挑牌開局；5＝無限試煉）。v5 存檔自動遷移（店主 11-13）：原本的唱片櫃都留成「認識」，挑過的王牌那幾組老闆送的四張、打倒藏家拿到的王牌算「擁有」，進行中的那一趟照留。v4（一晚版）存檔自動遷移（先到 v5 再到 v6）：唱片櫃、看過的、學會的、偏好、小人、配件留著，一晚的 run 丟掉，`nights` → `runs`、`best` → `{ far, checkpoints, bestStreak }`；更舊的（v3 以前）整份丟掉（只留聲音偏好與小人），標題下面寫一行提示。⏸ 選單可以重置。
- 依據：店主定案 `DECISIONS-v4`（下稱 D）、施工規格 `SPEC-v4`，以及店主之後的定案 FIXLIST 2／3／4／5／6／8／10（跟 D 不一樣的地方以 FIXLIST 為準）。各代理的施工紀錄在 `dev/notes-*.md`。

2. 每一手，你和他各暗中挑一張專輯、一個屬性，同時亮出。

- **再挑戰一趟**：門晃、老闆「……又是你。」「老樣子，《王牌》。」（不等點，各 1.6／2.4 秒自己走；王牌＝`save.lastAce`，不再三選一）→（唱片櫃有能帶的）挑種子 → 走到特價箱挑三張 → 來客第 1 位（包包 7 張；身上的配件帶過來，最多 3 件）。放棄這一趟（標題按兩下重新推門）也記進紀錄。
- **換王牌**（店主 11-13）：這一趟第 1 位開打前（序章那一趟＝序章打完之後；`engine.canSwitchAce`），來客畫面點老闆（熱點 `talk:owner`，櫃檯不開配件櫃時也算）→ 小面板「現在帶的：殿堂《…》」＋「聊聊」（照舊說一句）／「換一張王牌」（下面一行「老闆送的那幾張也跟著換」）→ 原本的王牌三選一面板（標題「想換一張？」、預設選中現在那張；選同一張＝不換，老闆「那就照舊。」）。換了（`engine.switchAce`）：包包裡老闆送的那幾張原位換成新那組（跳過包包裡已經有的；不夠就少），種子、特價箱、買的不動；新王牌與那組送的算擁有（gift）、`save.lastAce` 跟著改；藏家王牌撞到新王牌就照雜湊重抽；老闆「好，換這張。送你的也一起換了。」＋吐司。小面板下面還有一顆「賣給老闆」（第 A 波 5）。打過第 1 位（開打就算，`run.fought`）之後，兩位客人之間點老闆＝直接開櫃檯「賣給老闆」；其他時候只說一句（輪流「想換王牌？下一趟開門前再說。」）。第一次（序章那晚的來客提示看過之後）在第 1 位前的來客畫面，老闆頭上閃一下＋吐司「想換王牌，點老闆。」，只出一次（`save.seen.aceSwap`）。自動遊玩不換；重看教學照舊用當時的王牌。

### 從唱片櫃挑牌開局（店主 11-13；本機版，不接主站唱片櫃）

- **擁有 vs 認識**：`save.shelf[id]` 多 `own`（擁有）與 `src`（`gift` 老闆送的／`run` 一趟留一張＝店內取得金框／`boss` 打倒藏家拿到的王牌）。「認識」照舊（看過、拿過就算）。挑過哪個王牌，那組送的四張就算擁有。
- **種子**：第二趟起（`startAgain`：老闆那句說完、走去特價箱之前）開挑種子面板：唱片櫃裡擁有、不是頂點卡的（封面＋三色星數、店內取得金框），點選最多 3 張 →「就這幾張 ▸」；三色篩選；「先不挑」。包包＝種子＋老闆送的（這次挑的王牌那組）補到 4 張（重複的話送的往下補）＋特價箱 3 張＝7 張。序章那一趟不挑。種子在包包裡標「櫃裡帶來」（包包條金框）；不能換錢，但可以在櫃檯「交還老闆」（$0、之後不再算種子；第 A 波 5）。自動遊玩照最高星挑（`engine.seedPolicy`）。
- **掉落**：獎勵候選＝他這一場真的丟過的（無限試煉換牌、加星後那一副；王牌不掉），記進 `run.drops`（沒拿的也算）。序章男子那張（Eminem，第 2 手一定打出來）也算客人掉落（店主 11-13）。
- **一趟留一張**：結算「這一趟帶走一張 ▸」→ 面板：候選＝這一趟進過包包的（獎勵、買的、特價箱的；送的、種子不算）＋客人掉的，已經擁有的、頂點卡不列（`engine.keepCandidates`）；帶走＝擁有、金框「店內取得」，一趟只能一次（`engine.keepOne`、`run.kept`）。可以不帶。
- **唱片櫃頁**：上面「我的收藏 n 張」（店內取得在前、再來藏家的王牌、老闆送的），下面「認識過 m／316」（原本那面牆＋篩選）。
- 這一波不做：樂歷（種子格 3→4→5）、想要清單、主站登入、回寫主站。

## 除錯旗標

- `?seed=20261106`：指定日期種子。`?fast=1`：動畫 4 倍速。`?strict=1`：走不到就丟錯（e2e 用）。
- `?debug=1`：開 `window.__lab`
  - `__lab.autoplay('thoughtful')` 自動打完這場；`{until:'end'}` 一直打到這一趟結束（開局特價箱三張、升級三選一都自動挑；無限試煉不會自己結束，配 `loseNext`）；`{animated:true}` 用盤面真的點
  - `__lab.jump(23, {hp, maxHp, atk, def, level, xp, retryLeft, money})` 直接跳到第 23 位（`engine.jumpTo`；序章算完成、特價箱算挑過）；`__lab.skipTo(3)` 跳到這一輪第 4 位
  - `__lab.loseNext(1, {noRetry:true})` 下一場第一手就輸（n 場；noRetry＝這一輪的說情也用掉）；`__lab.forceWin()`／`forceLose()`；`__lab.force({kind:'counter',toE:3,toP:0})` 之後每手都照這個結果（`null` 取消）
  - `__lab.money(n)` 設錢；`__lab.shop()` 這一輪的貨；`__lab.timeline()` 逐句執行器的時間軸；`__lab.stageAction('crate:jazz')` 模擬點店裡的東西
  - `__lab.duelLab.start({enemy:'copycat', seed:7, hp, ehp, pos, atk, def, eAtk, eDef, hold})` 直接在對決畫面開一場（打完停在大章、不結算；pos＝照第幾位的曲線，atk／def＝你的品味／底氣；hold:true＝照真玩家揭曉後停住等點，沒給＝照原本時序）；`duelLab.setNext({i,attr})` 他下一手照這個出（e2e-duel 用）
