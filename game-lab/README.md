## 規則（規則卡六行，D §5 逐字）

1. 每張專輯有經典／冷門／硬蕊三個星數。
2. 每一手，你和他各暗中挑一張專輯、一個屬性，同時亮出。
3. 冷剋經、經剋硬、硬剋冷：剋中，就用你那個屬性的星數扣他聲望。
4. 被剋的一方高 2 星以上，剋不動，改成比星數。
5. 沒有相剋就比星數，高的扣差額；一樣大不扣。
6. 提示會暗示他這手的打算，但有些人會唬你。王牌 7 星，一場用一次。六手內沒分出勝負，比誰的聲望條剩得多。

（第 6 行照 FIXLIST 2／3 改。頁尾「你 10 聲望；客人 21–22、菁英 22–24、傳說藏家 24。」——客人、菁英、藏家的數字由 `C.rules.hpText` 照 `C.enemies[*].hp` 自動算。）

- **手牌**：包包裡隨機抽 3 張＋王牌。點封面＝選這張、自動選最高那一顆星；點別的星換屬性；只有「丟！」會出手（再點已選的星不會丟）。長按封面＝唱片資訊、試聽。
- **聲望**：你 10；一般客人 22（社團學長 21）、菁英 地下廠牌主理人 22／資深樂評 24、傳說藏家 24。一般 ≤ 菁英 ≤ 藏家（`sim.mjs` 的 HP 檢查）。序章男子 10（教學那場 18）。
- **他**：也有暗手 3 張，照原版的出招難度係數挑（`C.plannerByDepth`：第 1 位客人 normal、第 2、3 位 easy、菁英 normal、藏家 normal；序章男子 easy；normal 在你落後時會鈍一點）。他的封套揭曉前一直蓋著。
- **提示**：每手一句店裡的動作或一句話，藏著關鍵字（名盤／紀念版／大家都聽過＝經典；絕版／白版／沒人聽過＝冷門；噪音／聽不懂／實驗＝硬蕊），畫面上不寫屬性名。
- **唬人**：照機率（`C.honesty`：序章男子老實；一般客人約八成照實、菁英與藏家約七成五）。唬你的時候他出「剋掉你剋提示那招」的那色；王牌那手一定照實。誠實度**不顯示**（名牌、今晚來客都沒有；店主：看了很煩），從結果句「他唬你！」自己體會。
- **王牌**：那軸 7 星、一場一次。沒有「不會被剋」：被 ≤5 星剋＝高 2 星以上剋不動、改比星數（結果句跟一般剋不動一樣）；第一次丟王牌時老闆小提示「王牌 7 星，一場用一次。」
- **結果句**：揭曉後一句講清楚，順便教關鍵字，例：「冷門剋經典，命中！他 −4」「冷門剋經典，但他高你 2 星以上，剋不動。比星數，你 −3」「他唬你！『紀念版』是經典，他出的是硬蕊。你 −4」。
- **六手上限**：六手打完（或他牌出完）比**聲望條剩幾成**（剩餘÷滿血），一樣算你贏。大章「六手打完，比聲望條」＋「你剩 90%，他剩 70%：你贏」（% 用引擎 `pctPair`：整數一樣但勝負分得出來時寫一位小數）；兩邊真的一樣寫「一樣，算你贏」。整場最後一手播**整場贏家**的那張當勝利曲。
- **對手名牌**：只有名字（身分名），沒有副標、沒有誠實度。
- **教學**：「▶ 接受對決（看向老闆）」＝老闆帶的六手（同色比星數、冷剋經、經剋硬、硬剋冷、差 2 星剋不動、王牌），依你挑的王牌三種講法；「▶ 接受對決（手伸進袋子，準備出招）」＝直接開打。

## 一晚

```
21:30 推門 →（第一晚）序章男子 → 22:00 → 22:40 → 23:20（一般客人）→ 00:10 菁英 → 02:00 傳說藏家 → 打烊
```

- **序章**：猜今晚那張 → 三張王牌挑一張 → 老闆送四張 → 特價區 6 挑 3（免費）→ 八張放上櫃檯、飛進包包 → 男子進門、後走道對峙 → 接受對決。打贏：他走出門、地上留下 Fishmans《Long Season》（撿起面板沒有旁白）→ 配件三選一 → 今晚第一位客人推門進來。
- **今晚來客**：一般 6 抽 3（文青同好、社團學長、音響發燒友、二手店老闆、地下樂團吉他手、前衛樂迷）、菁英 2 抽 1（地下廠牌主理人、資深樂評）、傳說藏家最後；日期種子。店內底部一條，五顆頭像、錢（千分位）、包包、配件。鏡頭從上往下裁（`cameras.night`），矮螢幕也看得到門口牆。
- **贏了**：他丟過的唱片挑一張收進包包（最多 8 張）；菁英與藏家可以改拿配件。**輸了**：每晚一次老闆說情，同一位重打；序章男子輸了一律免費再一場。
- **再來一夜**：挑王牌 → 走到特價箱挑三張 → 今晚來客（包包 7 張；身上的配件帶過來）。

## 平衡（FIXLIST 10，R1；`node game-lab/sim.mjs --n 3000`，結果在 `dev/sim-v4.json`）

改成比聲望條之後，原本靠把客人聲望拉到 24–34 壓通關率，副作用是客人場 88% 打滿六手、77% 靠比聲望條分勝負，而且菁英、藏家的聲望比一般客人低。
R1 把客人聲望壓回 21–24（KO 幾乎只看客人聲望），改用出招難度與唬人率把通關率拉回來；六手、手牌 3 張、規則、經濟都沒動。

| 門檻 | R1（會讀的＋smart，N=3000） |
|---|---|
| S1 一晚通關 70–85% | 80.5% |
| S2 只出最大星／永遠剋提示／兩步公式／跟提示同色 ≤ S1 − 15 | 7.7／44.4／48.1／25.7% |
| S3 亂出 ≤5% | 0.0% |
| S4 客人場平均 4–6 手、≤3 手 ≤5%、最多 6 | 5.63 手、0.2%、6 |
| S5 序章男子 會讀的 ≥97%、≤4 手 | 100%、2.73 手 |
| S6 會買的 − 不買的 ≥5 點、不買的 ≥50% | 6.3 點、74.1% |
| S7 單場：一般最高減最低 ≤20 點、菁英 60–95%、藏家 45–85% | 76.9–94.7（17.9 點）、主理人 64.7／樂評 82.8、藏家 47.9% |
| S8 先知 ≥97% | 99.5% |
| **S9 客人場由 KO 結束（任一方）≥35%** | **48.9%**（你 KO 他 45.3%、他 KO 你 3.6%）；比聲望條 51.1% |
| **HP 聲望 一般 ≤ 菁英 ≤ 藏家** | 21–22 ≤ 22–24 ≤ 24 |

一晚裡各級：一般 勝 87.6%、KO 47.3%；菁英 勝 91.7%、KO 52.1%；藏家 勝 79.6%、KO 50.8%（他 KO 你 8.9%）。客人場 72% 打到第 6 手（原本 88%）。
可行區很窄：你 11 → 通關 87%（超過 85）、你 9 → 菁英／藏家單場過不了 S7；客人聲望全 +2 → 藏家單場 44%。最貼線的是 S6、S7 一般差距、藏家單場。

## 除錯旗標

- `?seed=20261106`：指定日期種子。`?fast=1`：動畫 4 倍速。`?strict=1`：走不到就丟錯（e2e 用）。
- `?debug=1`：開 `window.__lab`
  - `__lab.autoplay('thoughtful')` 自動打完這場；`{until:'end'}` 一整晚；`{animated:true}` 用盤面真的點
  - `__lab.skipTo(3)` 跳到今晚第 4 位；`__lab.forceWin()`／`forceLose()`；`__lab.force({kind:'counter',toE:3,toP:0})` 之後每手都照這個結果（`null` 取消）
