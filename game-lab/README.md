# 品味對決・試做版（game lab）

以 `roguelike.html` 的卡牌遊戲為基底，重做一版「從序章就好玩」的試做。獨立頁面，**沒有動到正式頁**，也沒有寫 Firestore／KV（封面在建置時烤進 `cards.js`）。

- 網址：`/game-lab/`（本機：`python3 -m http.server 8765` 後開 `http://localhost:8765/game-lab/`）
- 手機直式 390px 為主；對決畫面塞得進 390×660 不用捲。
- 存檔只寫 `localStorage['dipGameLab_v1']`，不碰 `dipRogueMeta_v2`。⏸ 選單可以重置。

## 怎麼玩

1. 推門。音響在放一張真的唱片，老闆問你是哪一張（猜中有「好耳朵」）。
2. 三張王牌挑一張帶走（點封套可以換著聽）。老闆再送四張、門口一百塊三張。
3. 嗆你品味的男子進門，第一場品味對決。
4. 每一手：點一張盤，再點屬性（經典／冷門／硬蕊）。
   - 對手的唱片正面朝上，他嘴上喊的是那張最高的那軸。
   - 他真正出什麼，看櫃檯上的「氣場唱盤」：六格隨機落一格。真＝照喊的出，晃＝出剋你剋招的，跟／報／盯讀的是你。
   - 屬性鈕上直接印出「他出各屬性時這手的結果」，照不照做都真的結算。
5. 打贏，他押的那張盤翻開、真的播，收進唱片櫃。
6. 之後是交流夜：21:30 到 02:00 的時間軸，往右選人或去挖箱、試聽機、事件、櫃檯。打烊前傳說藏家推門。
7. 死了或打烊，看結算（輸在哪一手、品味分數、今晚認識的盤），「再來一夜」10 秒內回到地圖。

## 跟正式版差在哪（為什麼）

| 正式版 | 試做版 | 為什麼 |
|---|---|---|
| 到第一個自己出牌要 61 次點擊、6–9 分鐘 | 3 次點擊、約 13 秒就有第一個決定（猜歌）；8 次點擊、約 42 秒開打第一手（實測） | 序章太長是「不好玩」的頭號原因 |
| 看敵人心聲猜、剋最可能的顏色幾乎必勝 | 公開的「氣場唱盤」＋虛晃；模擬整晚過關率：永遠剋氣場 11%、舊公式 31%、讀盤 60%、算期望值 83% | 要「讀人」，不是背公式 |
| 結果要自己算 | 每手一行算式橫幅（輸的原因一定寫出來） | 輸了看得懂 |
| 三圍、流派、樂歷、現金、耗損、DDA | 全拿掉；改成賭注遞增、氣勢、品味輾壓、七星回擊、12 件發燒配件 | 規則少、每手都有賭注 |
| 場景在外面跑 | 整晚都在店裡（客人一個個推門進來） | 零新美術，維持店的味道 |
| 獎勵多半是數值 | 押盤翻開真的播、唱片櫃「已認識 N／M」、讀人圖鑑 | 贏＝認識一張盤 |

聲光：同時亮牌、唱針落格、讀中／看穿／虛晃章、打擊停頓與震屏、七星回擊全螢幕、WebAudio 合成音效（不載音檔）、大時刻換歌（iTunes 試聽，抓不到 2.5 秒就放棄，不擋動畫）。

## 除錯旗標

- `?seed=20261106`：指定日期種子（同一天大家的第一晚一樣）。
- `?fast=1`：動畫 4 倍速。
- `?debug=1`：開 `window.__lab`
  - `__lab.autoplay('ev')` 自動打完這場；`__lab.autoplay('ev', {until:'end', animated:true})` 用動畫自動玩一整晚
  - `__lab.skipTo(6)` 跳到第 6 欄（Boss）；`__lab.forceLose()` 這場直接輸；`__lab.duel()` 看對決狀態
- 對決單獨測：`/game-lab/dev/duel-harness.html?enemy=boss&ace=heresy`
- 靜態線框：`/game-lab/mock.html`

## 店主待決清單

1. **敵方唱片正面朝上**（「他把下一張擺上唱盤」，屬性仍暗）。過去拿掉過「唱片堆顏色洩漏主屬性」。
2. **流亡王牌改用 Barney Wilen《Zodiac》**：現役 Deerfield《Nil Desperandum》沒有試聽，猜歌用不了。
3. **氣場唱盤的樣子**：唱片圈標＋唱針、不出輪盤聲；色點＝真實機率。⏸ 裡有「進階：自己讀唱盤」可以比較。
4. **霸權改成「王牌被剋，這手互不傷害」**（現行：取消相剋改比星，王牌零風險）。
5. **七星回擊要屬性對得上**（王牌那軸剋得到他的輾壓屬性）。
6. **割捨防禦改成「出一張剋得到的盤，用它的星擋輾壓」**（名詞保留，做法變了）。
7. **品味輾壓維持保證命中並作廢他這手**；傷害改成當下氣勢（6–10），存越多越痛。
8. **拿掉的系統**：三圍、流派、樂歷、現金、耗損、DDA、場子變熱（`CFG.heatQi` 留著）。
9. **新台詞**（`LINES-REVIEW.md`）與**玩家回嘴兩句**。
10. **門口一百塊三張**用大師的弱作（鮑伊、邁爾士、Devo）的口吻是否 OK。
11. **敵人名字**取自店主的名字產生器，頭銜沿用現行。
12. **聲音預設**：「推門（有聲音）」會把 DipPlayer 的自動試聽偏好設成開。
13. **點播只加你的盤**（中性用語）。
14. 結算的「品味分數」公式。

另外三件實作時定的，也請過目：

- **數值**：玩家聲望 22→**20**、傳說藏家 24→**26**（為了讓「舊公式」整晚過關率壓在 35% 以下）。
- **換盤**：挖箱台灣區的草東沒有派對《瓦合》換成大象體操《角度》（樂團名會讓「派對」上畫面）；金邊私藏池換掉兩張跟別的池重複的盤。
- **序章一定是第一次玩才有**；之後每晚從挑王牌直接進地圖。

評審後的小規則（引擎測試＋sim 48 條都重跑過）：

- **經典回血在扣血之後才封頂**（SPEC §3.3 第 5→6 步）：滿血時被打，出經典的 +1 仍然抵得掉一點；滿血又沒挨打就不飄「＋聲望」。
- **回血溢出變氣勢**：試聽機、櫃檯喝茶、事件、重複配件的回血，滿出來 3 點以上 → 下一場開局氣勢 +1（每場最多 +2）。畫面寫「聲望已滿：改成下一場開局氣勢 +1」。
- **看穿收尾**：用看穿打倒對手，結算多一行「看穿收尾 ×N」（每次 50 分）。
- 同一晚的押盤不重複、不跟起手包包撞；挖箱／事件／試聽機抽盤會避開包包裡和今晚押著的盤（避免兩張同盤共用「洗過」）。
- 序章回嘴選「你耳機裡那張，是《Mylo Xyloto》吧。」，第一手他亮出的就是那張（他說「……對啦，就這張。」）。
- 九成新事件的「算了」改成回 2 聲望；試聽機只放 15 秒，放完可以點唱機再聽一次。
