# 品味對決・試做版 v4（game lab）

以 `roguelike.html` 的卡牌遊戲為基底的試做。獨立頁面，**沒有動到正式頁**，也沒有寫 Firestore／KV（封面、試聽、平台連結都在建置時烤進 `cards.js`，`tools/bake-cards.mjs` 只讀 Firestore 公開 REST）。

- 網址：`/game-lab/`（本機：在 repo 根目錄 `python3 -m http.server 8765`，開 `http://localhost:8765/game-lab/`）
- 手機直式優先。驗收尺寸＝**390×664、375×548、430×932、360×640**，四個都不用捲。
- 存檔只寫 `localStorage['dipGameLab_v1']`（存檔版本 6＝從唱片櫃挑牌開局；5＝無限試煉）。v5 存檔自動遷移（店主 11-13）：原本的唱片櫃都留成「認識」，挑過的王牌那幾組老闆送的四張、打倒藏家拿到的王牌算「擁有」，進行中的那一趟照留。v4（一晚版）存檔自動遷移（先到 v5 再到 v6）：唱片櫃、看過的、學會的、偏好、小人、配件留著，一晚的 run 丟掉，`nights` → `runs`、`best` → `{ far, checkpoints, bestStreak }`；更舊的（v3 以前）整份丟掉（只留聲音偏好與小人），標題下面寫一行提示。⏸ 選單可以重置。
- 依據：店主定案 `DECISIONS-v4`（下稱 D）、施工規格 `SPEC-v4`，以及店主之後的定案 FIXLIST 2／3／4／5／6／8／10（跟 D 不一樣的地方以 FIXLIST 為準）。各代理的施工紀錄在 `dev/notes-*.md`。

## 規則（規則卡六行，D §5 逐字）

1. 每張專輯有經典／冷門／硬蕊三個星數。
2. 每一手，你和他各暗中挑一張專輯、一個屬性，同時亮出。
3. 冷剋經、經剋硬、硬剋冷：剋中，就用你那個屬性的星數扣他聲望。
4. 被剋的一方高 2 星以上，剋不動，改成比星數。
5. 沒有相剋就比星數，高的扣差額；一樣大不扣。
6. 提示會暗示他這手的打算，但有些人會唬你。王牌 7 星，一場用一次。六手內沒分出勝負，比誰的聲望條剩得多。

六行下面另起一段「為什麼這樣剋：冷門笑經典太大眾，經典壓得住難懂的硬蕊，硬蕊拆穿只是沒人聽過的冷門。」（`C.rules.why`，店主 11-12）。

（第 6 行照 FIXLIST 2／3 改。頁尾「你 12 聲望，打贏回 3；客人 12、傳說藏家 14。」——「你 12」是固定字（check-content 對 `CFG.playerHp`），客人、藏家的數字由 `C.rules.hpText` 照 `C.trial.guestHp` 算。）

- **手牌**：包包裡隨機抽 5 張＋王牌（FIXLIST 11；`CFG.handSize`；打出一張補一張，牌堆抽完把丟過的洗回）。
  疊成水平一排、往右錯開 3 成寬（不轉角、不成弧形；王牌金框在最右、最上面；用過就不在裡面；不顯示星數）。**每張封面一樣大，疊著、打開都一樣**（v5 手風琴，店主 11-09）：
  點一張（露出來那一條）＝在那張打開——它右邊那疊往右滑開（180 ms；減少動態＝直接換）、那張整張露出來並浮起 6 px，正上方跳三顆屬性鈕（經 n／冷 n／硬 n，最高那顆大一點、黑框；王牌只有一顆「王牌 經 7」），**那張和它左邊的牌不動**、其他牌照樣疊著（審查 F4）；
  所以疊著那排不置中：起點盡量置中、但不超過「打開哪一張左邊都不用動」的位置（390／430／360 靠左、右邊留 76／88／60 px；375 偏左 17 px）。打開時右邊那疊露出來那一條先收窄（最窄 22%），還放不下才把左邊那幾條收一點（390／430 打開第 5 張那張挪 8／6 px；360 打開第 3、4、5 張挪 4／13／22 px）；打開最右那張（王牌）＝只浮起、其他不動 → 點屬性鈕＝照那個屬性丟出。
  點別張＝換那張打開；再點打開的那張、或點手牌外面（牌桌、他那一塊、店景）＝收回疊好，手牌區的空白、你那一列、「你丟的」預覽、屬性鈕之間的縫都不算（H3）；雙擊的第二下（同一點 320 ms 內）不算「再點＝收回」；丟出後也收回。打開那張浮起後底下露出來的 6 px 也算那張（點封面下緣下面一點＝再點那張，不會打開底下左邊那張；F3）。
  屬性鈕往上蓋「你」那一列（不蓋提示句），整組跟著打開那張（中心在那張上面）：讓得開就讓開「你」＋發燒配件與聲望數字；讓開就會跑到右邊那疊上面的話不讓，把蓋到的「你」／配件先藏起來（不露出半截），收回再出來（審查 F1／F2；聲望數字四個尺寸都沒被藏過）。打開時「你丟的」格是那張的半透明預覽（屬性＝最高那顆；最高並列時大鈕跟著預覽那顆；滑鼠移到別顆＝預覽那顆）。長按封面＝唱片資訊、試聽（疊著也行；放開手指那一下不會按到資訊裡的「關閉」或串流鈕；揭曉時連點牌桌開了資訊，同一串連點也不會按到）；按住屬性鈕＝一行小字「經典 5 星」，不出牌（按多久放開都一樣）。盤面還在滑進來就點了一張＝進場完就打開那張。換手時留下的牌滑到新位置（180 ms）。
  手牌封面（四個驗收尺寸）：390×664 115 px、375×548 97 px、430×932 128 px、360×640 111 px；露出那一條疊著 35／29／38／33 px，打開時右邊那疊 27–33／29／32–36／24–27 px（看打開哪一張）。
- **聲望**（無限試煉）：你 12、**帶到下一場**，打贏回 3（不超過上限）；客人 12、傳說藏家 14。序章男子 10（教學那場 18）。`C.enemies[*].hp`（一般 20–25…藏家 28）只剩直接開打的對決（`__lab.duelLab`、sim S7）在用。
- **他**：也有暗手 3 張，出招難度照位數（曲線 V3，`C.trial.curve`：第 1–2 位 easy、3–4 位 normal、第 5 位起 hard＝原版 `enemyForDepth`；序章男子 easy；normal／hard 在你落後時會鈍一點、也少唬一點）。他的封套揭曉前一直蓋著。
- **品味／底氣**（無限試煉，名字是店主暫定）：你的品味＝剋中時多扣他幾點；客人的品味＝只要扣到你就多扣；底氣＝被扣時少扣、最多擋一半（`max(⌈x/2⌉, x−底氣)`，兩邊一樣）。客人的品味／底氣照位數長（藏家 +1），你的靠升級。對決時兩邊名字列有「品 n」「底 n」小籤（大於 0 才有；讀屏念「品味 n」），結果句多一句「品味：多扣 1」「他的底氣：少扣 1」，那顆小籤閃一下（補充句放不下就自己另起一行）；扣血的「−n」浮在聲望數字正下方。規則卡頁尾、聲望那顆點開、客人頭像點開都有一句說明。
- **提示**：每手一句店裡的動作或一句話，藏著關鍵字（名盤／紀念版／大家都聽過＝經典；絕版／自主發行／沒人聽過＝冷門；噪音／聽不懂／實驗＝硬蕊），畫面上不寫屬性名。
- **唬人**：照機率（無限試煉照位數：第 1–2 位不唬、3–4 位 85% 照實、第 5 位 82% 起每位少 5 點、第 13 位起封底 45%；序章男子老實）。唬你的時候他出「剋掉你剋提示那招」的那色；王牌那手一定照實。誠實度**不顯示**（名牌、來客都沒有；店主：看了很煩），從結果句「他唬你！」自己體會。
- **王牌**：那軸 7 星、一場一次。沒有「不會被剋」：被 ≤5 星剋＝高 2 星以上剋不動、改比星數（結果句跟一般剋不動一樣）；第一次丟王牌時老闆小提示「王牌 7 星，一場用一次。」
- **結果句**：揭曉後一句講清楚，順便教關鍵字，例：「冷門剋經典，命中！他 −4」「冷門剋經典，但他高你 2 星以上，剋不動。比星數，你 −3」「他唬你！『紀念版』是經典，他出的是硬蕊。你 −4」。
- **六手上限**：六手打完（或他牌出完）比**聲望條剩幾成**（剩餘÷滿血），一樣算你贏。大章「六手打完，比聲望條」＋「你剩 90%，他剩 70%：你贏」（% 用引擎 `pctPair`：整數一樣但勝負分得出來時寫一位小數）；兩邊真的一樣寫「一樣，算你贏」。整場最後一手播**整場贏家**的那張當勝利曲。
- **對手名牌**：只有名字（身分名），沒有副標、沒有誠實度。
- **牌桌小抄**：點牌桌上的小相剋圖＝打開小抄（冷剋經／經剋硬／硬剋冷各一句白話＋「差 2 星以上 剋不動，比星數」；`C.cheatSheet`），再點一下（哪裡都行）收起；點在別處那一下照常有作用（點手牌照樣打開那張）。結算中點相剋圖＝照舊 4 倍速，不開小抄。教學中有遮罩，點不到。
- **教學**：「▶ 接受對決（看向老闆）」＝老闆帶的六手（同色比星數、冷剋經、經剋硬、硬剋冷、差 2 星剋不動、王牌），依你挑的王牌三種講法；手牌 5 張＝老闆四張（照教的順序）＋特價箱挑的第 1 張，第 5 手「剋不動」指的一定是特價箱那張（`C.tutorial.script`，男子的暗手照舊 3 張）；「▶ 接受對決（手伸進袋子，準備出招）」＝直接開打（鈕下面一行小字「跳過教學」，`promptSubs`）。
  唱盤前（只在「看向老闆」那條路）：三人站定後、遇敵前，面板攤開猜歌那三張（封面、經典／冷門／硬蕊 7、`C.aceGloss` 一行白話）＋相剋圖＋老闆的話，六句（`C.tutorial.intro`）：第 1 句三張各亮自己那一色，「冷→經／經→硬／硬→冷」三句各亮那一條箭頭（那兩張亮、第三張淡），最後一句三條都亮。點面板＝下一句（不點照對白框的閱讀時間往下走），講完最後一句留在對白框、接著遇敵。重看教學、續玩不出現。

  高螢幕（430×932 這類）：店景在寬度上已經是整間店，對白框與包包條照內容高，下面剩的高改成店裡的木地板往下接（`DipLabStage.floorExt`，序章／尾聲的 scene 畫面與來客；抽屜開著時不接，抽屜上面照 R2 是舞台黑），不留白（V03、V5）。開面板時面板要的高先從地板讓，地板讓完還不夠才收鏡頭（只裁放不下的那幾列；收成對決那條時橫條往上長到剛好放得下面板）。

### 從唱片櫃挑牌開局（店主 11-13；本機版，不接主站唱片櫃）

- **擁有 vs 認識**：`save.shelf[id]` 多 `own`（擁有）與 `src`（`gift` 老闆送的／`run` 一趟留一張＝店內取得金框／`boss` 打倒藏家拿到的王牌）。「認識」照舊（看過、拿過就算）。挑過哪個王牌，那組送的四張就算擁有。
- **種子**：第二趟起（`startAgain`：挑王牌之後、走去特價箱之前）開挑種子面板：唱片櫃裡擁有、不是頂點卡的（封面＋三色星數、店內取得金框），點選最多 3 張 →「就這幾張 ▸」；三色篩選；「先不挑」。包包＝種子＋老闆送的（這次挑的王牌那組）補到 4 張（重複的話送的往下補）＋特價箱 3 張＝7 張。序章那一趟不挑。種子在包包裡標「櫃裡帶來」（包包條金框），不能賣回（先賣子面板選不了，點了說「從唱片櫃帶來的不能賣」；拿獎勵包包滿時照舊可以拿掉）。自動遊玩照最高星挑（`engine.seedPolicy`）。
- **掉落**：獎勵候選＝他這一場真的丟過的（無限試煉換牌、加星後那一副；王牌不掉），記進 `run.drops`（沒拿的也算）。序章男子那張（Fishmans）是原版劇本的，不算客人掉落。
- **一趟留一張**：結算「這一趟帶走一張 ▸」→ 面板：候選＝這一趟進過包包的（獎勵、買的、特價箱的；送的、種子不算）＋客人掉的，已經擁有的、頂點卡不列（`engine.keepCandidates`）；帶走＝擁有、金框「店內取得」，一趟只能一次（`engine.keepOne`、`run.kept`）。可以不帶。
- **唱片櫃頁**：上面「我的收藏 n 張」（店內取得在前、再來藏家的王牌、老闆送的），下面「認識過 m／289」（原本那面牆＋篩選）。
- 這一波不做：樂歷（種子格 3→4→5）、想要清單、主站登入、回寫主站。
